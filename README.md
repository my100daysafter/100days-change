# 100일의 변화

## 실행
- 압축을 푼 뒤 `index.html`을 브라우저에서 열면 기본 기능을 사용할 수 있습니다.
- 온라인 공개 및 홈 화면 설치(PWA)를 위해서는 HTTPS로 호스팅해야 합니다.

## 무료 배포 권장: GitHub Pages
1. GitHub 계정을 만들고 새 Public repository를 만듭니다. 예: `100days-change`
2. 이 폴더 안의 파일 3개(`index.html`, `manifest.webmanifest`, `sw.js`)를 저장소 최상위에 업로드합니다.
3. 저장소 Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save를 선택합니다.
4. 잠시 뒤 `https://깃허브아이디.github.io/100days-change/` 주소로 공개됩니다.

## 중요한 저장 방식
- 현재 버전은 각 사용자의 브라우저에 기록을 저장합니다(localStorage).
- 따라서 공유 링크로 여러 사람이 접속해도 각자의 브라우저 기록은 서로 섞이지 않습니다.
- 다만 계정 로그인, 기기간 자동 동기화, 중앙 서버 백업은 포함하지 않습니다. 기기 변경 전 앱 안의 '기록 백업하기'를 이용해야 합니다.
- 여러 기기에서 같은 계정으로 기록을 동기화하려면 별도 데이터베이스와 인증 기능을 추가해야 합니다.
